# Secure Active Directory Users and Computers Management in Windows Server 2022

## Project Overview
This project demonstrates the setup and administration of Active Directory Users and Computers (ADUC) in a virtual cybersecurity lab using Windows Server 2022 and Oracle VirtualBox.

The project focuses on centralized user management, organizational units, access control, and security policy verification in a Windows domain environment.

## Objectives
- Configure a Windows Server 2022 domain environment.
- Manage users and Organizational Units (OUs) using ADUC.
- Organize users into departments such as IT and Sales.
- Explore Group Policy and security administration.
- Verify policy updates in a Windows client environment.

## Technologies Used
- Windows Server 2022
- Active Directory Domain Services (AD DS)
- Active Directory Users and Computers (ADUC)
- Oracle VirtualBox
- Windows 10 client
- Group Policy Management
- Kali Linux (supporting lab environment)

## Practical Work
1. Virtual lab environment setup.
2. Domain configuration and Active Directory administration.
3. Organizational Unit and user configuration.
4. Group Policy application and verification.
5. Documentation through practical screenshots.
