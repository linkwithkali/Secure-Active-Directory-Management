Project Overview

This project demonstrates Active Directory Users and Computers (ADUC) administration in a virtual lab. It explores centralized account management, Organizational Units, and Group Policy verification.

Project Objectives

  • Configure a Windows Server domain environment.
  • Manage users and Organizational Units using ADUC.
  • Organize accounts for departments such as IT and Sales.
  • Explore Group Policy and access-control concepts.
  • Verify policy updates in a Windows client environment.

Technologies Used

Windows Server 2022 Active Directory Domain Services ADUC VirtualBox Windows 10 Group Policy Kali Linux

Practical Implementation

  1. Virtual lab environment setup.
  2. Domain and Active Directory configuration.
  3. User and Organizational Unit management.
  4. Group Policy application and verification.
  5. Project documentation and screenshot evidence.
